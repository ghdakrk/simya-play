# 심야기원 — 안내 사이트

이 사이트는 스토어 안내 · 이용약관 · 개인정보 처리방침 · 환불 안내 · 사업자 정보만 둡니다. GitHub Pages로 공개합니다.

- `privacy.html`, `terms.html`, `refund.html`, `business.html`: 플레이 콘솔과 앱 안(설정 아래 링크)에서 링크하므로 **지우거나 옮기지 말 것**
- 원본은 `ghdakrk/GAMEGO` 저장소의 `store/site/` 폴더다. 고칠 때는 원본을 고친 뒤 이 저장소에 복사한다
- 처리방침을 바꾸면 시행일과 변경 내용을 페이지에 적고, 앱이 보내는 정보가 바뀌면 플레이 콘솔 「데이터 보안」 답도 같이 고친다
- GitHub Pages: Settings → Pages → Deploy from a branch, `main` / `(root)`. 주소는 `https://ghdakrk.github.io/simya-play/`
